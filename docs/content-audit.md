# 콘텐츠 정확성 점검 기록

이 앱은 어린이·새신자가 보고 배울 수 있으므로, 성경 본문과 어긋나는 내용이 있으면 안 된다.
모든 콘텐츠는 `src/content/*.json`에 있고, 아래 두 겹으로 점검한다.

## 1. 기계 검증 (매번)
- `node scripts/verify-missions.mjs` — 손으로 쓴 미션 5개 파일의 모든 인용문(`"…"`, `'…'`)이 `hintVerse` 범위의 개역한글 본문에 그대로 있는지 확인. 0 errors여야 한다.
- `src/content/missions-generated.json`(빈칸 채우기 310, 말씀 조각 60)은 본문에서 기계 생성하므로 인용 오류가 생길 수 없다. 원본 선정은 `scripts/verse-picks.json`.
- `vitest` — 미션 참조 장 존재, 정답 인덱스 유효, 지도 도시 id 등 구조 검증.

## 2. 사람 검토 (2026-09-22 전수)
카드 135장, 인물 33명·관계 32개, 손으로 쓴 미션 181개, 지도 규칙 63개, 화면 문구를 본문과 대조했다.

수정한 것:
- 지도: 행 5장→유대 점등을 행 8장으로(행 8:1). 안디옥은 예루살렘에서(행 11:19). 골로새는 행 20장이 아니라 행 19장 에베소 사역에서(행 19:10, 골 2:1). 계 1장에 밧모 추가(계 1:9).
- 카드 도마: "손을 옆구리에 넣고서야" → 본문은 만졌다고 기록하지 않음(요 20:27-28). 문구 수정.
- 카드 마가복음 4장 겨자씨: "큰 나무" → 개역한글은 "큰 가지"(막 4:32).
- 카드 루디아: "유럽 첫 신자" → 본문 표현대로 "빌립보에서 처음 믿은".
- 카드 요한: 요 1:35-40의 '다른 제자'를 요한으로 보는 것은 전통적 해석임을 명시.
- 인물 고넬료 "첫 이방인 신자" → "성령 받은 이방인 백부장"(에디오피아 내시 등 논쟁 회피).
- 인물 마가 "복음서 기록자" → "기록자로 전해짐"(전승). 마가↔베드로 "통역"(파피아스 전승, 성경 밖) → "'내 아들 마가'(벧전 5:13)". 바나바↔마가 "사촌" → 개역한글 표현 "생질"(골 4:10).
- 관계 스데반↔바울 방향·문구 정리(행 7:58).
- 미션 막 5장 귀신 이름: 보기 '레기온'은 '군대'와 같은 뜻이라 제거. 요 9장 보기 '실로암의 걸인'은 정답 인물과 겹쳐 제거. 요 21장 '일백 오십 세' → 본문 표기 '일백 쉰 세'. 빌립보 감옥 선택 미션을 행 17장에서 행 16장으로 이동.
- 배달 미션 힌트: 골로새 "빌레몬의 고향"(추정) → "에바브라가 전한 교회"(골 1:7). 데살로니가 "수도"(역사 지식) → "세 안식일 강론한 도시"(행 17:2).

확인했으나 해석이 들어가는 항목(성경이 명시하지 않음, 통상적 이해로 둠):
- 디모데후서 교회 위치 로마(집필지), 히브리서·유다서 예루살렘, 베드로서 "흩어진 성도".
- 누가 = 행 16:10 '우리' 단락의 기록자, 마가 = 마가복음 저자, 요한 = 요한복음 저자 (전통적 저작설).

## 3. 새 콘텐츠를 넣을 때
1. 인용문은 반드시 개역한글 본문 그대로, `hintVerse`에 그 범위를 적는다.
2. `node scripts/verify-missions.mjs` 0 errors 확인.
3. 정답이 둘 이상 될 수 있는 보기(동의어, 같은 인물의 다른 호칭)를 넣지 않는다.
4. 성경 밖 전승(저자, 지명 역사)은 "전해진다/여겨진다"로 표시한다.
