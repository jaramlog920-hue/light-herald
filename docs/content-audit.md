# 콘텐츠 정확성 점검

이 게임은 기초 신앙이 없는 사람이나 어린이가 혼자 해도 **틀린 지식이 남으면 안 된다**.
그래서 모든 문구는 아래 원칙을 지키고, 기계 검증을 통과해야 한다.

## 원칙
1. **인용은 개역한글 본문 그대로.** 따옴표 안의 말은 한 글자도 바꾸지 않는다.
   다른 번역본 표현(낙타털, 위로의 아들, 언변이 좋고 …)을 쓰지 않는다.
2. **성경이 말하지 않는 것은 단정하지 않는다.** 저자·수신지·지리처럼 전승이나
   학설에 기대는 내용은 빼거나 "전해진다"로 표시한다.
3. **교파마다 해석이 갈리는 구절은 해석을 붙이지 않는다.** (예: 마 16:18 "이 반석")
4. **동명이인은 반드시 구분한다.** (빌립 / 야고보 / 나사로 / 아나니아 / 유다)
5. **정답이 둘이 될 수 있는 보기를 만들지 않는다.**

## 기계 검증 — `npm run verify`
- `verify-missions.mjs` : 손으로 쓴 미션 181개의 모든 따옴표 인용(264개)이
  `hintVerse` 범위의 본문에 그대로 있는지.
- `verify-cards.mjs` : 카드 137장의 인용, 카드가 속한 장과 인용 절의 일치,
  '말씀 조각' 카드 요약이 본문 그대로인지. (제목이 '팔복'처럼 이름표인 카드는
  `titleIsLabel: true`로 표시해 제목만 예외로 둔다.)
- `verify-generated.mjs` : 생성 미션 370개(빈칸 310·말씀 조각 60)에 대해
  정답을 넣은 문장이 본문에 있는지, **오답 보기를 넣으면 본문이 되지 않는지**.
- `npm test` : 구조 검증(미션이 가리키는 장의 존재, 보기 번호, 지도 도시 id 등).

세 검증기는 일부러 틀린 값을 넣어 실제로 잡아내는지 확인했다.

## 본문 데이터
`src/content/nt-krv.json` — 27권, 장수·절수를 표준과 대조했고 빈 절·깨진 문자·
태그·엔티티가 하나도 없다. 고후 13장 13절, 요삼 15절, 계 8장 13절은 개역한글의
실제 절 구분이다(KJV와 다름).

## 2026-09-22 전수 점검에서 고친 것

**번역본이 섞인 표현**
- 세례 요한 힌트 "낙타털" → **"약대 털옷"** (마 3:4)
- 바나바 "위로의 아들" → 개역한글은 **"권위자"**(행 4:36). 역할을 행 11:24 표현으로 교체
- 아볼로 "언변이 좋고" → **"학문이 많고"** (행 18:24)
- 브리스길라와 아굴라 "천막" → **"장막"** (행 18:3)
- 요 21장 "일백 오십 세" → **"일백 쉰 세"** (요 21:11)

**인용이 본문과 달랐던 것**
- 눅 4:18("이는" 누락), 눅 19:9, 행 3:6(그리스도 누락), 롬 8:39("다른 아무"),
  요일 1:9("우리를" 누락), 계 3:20, 계 22:21("있을찌어다"), 유 1:24,
  마 22:37-39, 막 4:32, 마 26:26-28, 막 5:41 — 모두 본문 그대로로 교정
- 제목 자체가 달랐던 것: 요 6:35 "나는 생명의 떡이니" → **"내가 곧 생명의 떡이니"**,
  벧전 5:7 "맡기라" → **"맡겨 버리라"**, 히 4:12, 히 12:2

**성경이 말하지 않는데 단정했던 것**
- 요한복음 저자·"사랑하시는 제자" 동일시 → 요한 인물 카드를 이름이 직접 나오는
  **마 4:21-22**로 옮김
- 누가를 행 16장 '우리'의 기록자로 단정 → **골 4:14 "사랑을 받는 의원"**으로 옮김
- 마가를 마가복음 저자로 단정 → **"바나바의 사촌이자 바울의 동역자"**(골 4:10, 몬 1:24)
- 마가↔베드로 "통역"(파피아스 전승) → **"'내 아들 마가'"**(벧전 5:13)
- 고넬료 "첫 이방인 신자" → **"성령 받은 이방인 백부장"**
- 루디아 "유럽 첫 신자" → **"두아디라의 자주 장사"**
- 막달라 마리아 카드의 근거를 사본에 따라 괄호로 묶인 막 16:9 → **막 16:1-2**로
- 지도: **히브리서·유다서·요한1~3서는 받는 곳이 본문에 없어 교회를 세우지 않는다.**
  야고보서는 "흩어져 있는 열 두 지파"(약 1:1)이므로 '흩어진 성도'로 옮김
- 밧모·여리고·에베소에 대한 지리 상식 힌트 → 본문 근거로 교체

**해석이 갈리는 것**
- 마 16:18 "이 반석" 해석을 붙였던 베드로 카드 → **"'너는 베드로라' 하신 제자"**로
- 4회차 칭호 "빛을 전하는 사도" → **"빛 가운데 행하는 자"**(사도직 논란 회피)
- 선택 미션 피드백의 사견 2건(엡 4:26, 약 4:15) → 본문 인용으로 교체

**혼동을 부르던 것**
- 빌립에 "(사도 빌립과 다른 사람)" 명시
- 야고보를 "야고보(세베대의 아들)" / "야고보(주의 형제)"로 구분
- 눅 16장 나사로에 "요 11장의 나사로와 다른 사람" 명시
- 행 9장 아나니아에 "행 5장의 아나니아와 다른 사람" 명시
- 막 8장 가이사랴 빌립보에 "해안의 가이사랴와 다른 곳" 명시
- 정답이 둘이 될 수 있던 보기 제거: 막 5장 '레기온/군대', 요 9장 '실로암의 걸인'

**앞선 점검에서 고친 지도 규칙**
- 유대·사마리아 점등을 행 5장 → **행 8장**(행 8:1)
- 안디옥을 가이사랴 → **예루살렘**에서(행 11:19)
- 골로새를 행 20장 → **행 19장** 에베소 사역에서(행 19:10, 골 2:1)
- **계 1장에 밧모** 추가(계 1:9)

## 남은 판단 (성경이 명시하지 않아 통상적 이해를 따른 것)
- 디모데후서를 로마에 둔 것 (딤후 1:17 "로마에 있을 때에")
- 빌레몬서를 골로새에 둔 것 (골 4:9의 오네시모, 골 4:17·몬 1:2의 아킵보)
- 1차 전도여행의 셋째 기착지를 '갈라디아'로 표기한 것 (비시디아 안디옥)
- 스데반을 '첫 순교자'라 부른 것
이 네 가지는 교회에서 널리 통용되는 이해이며, 더 엄격히 가려면 여기서부터 손대면 된다.

## 콘텐츠를 새로 넣을 때
1. 인용은 본문 그대로, `hintVerse`에 그 범위를 정확히 적는다.
2. `npm run verify && npm test` 가 모두 통과해야 한다.
3. 위 원칙 1~5에 걸리면 넣지 않는다.
